## Changes made in this sprint

1. **Outcome labels.** The UI used to show "Verified safe" for deployments and rollbacks alike. It now shows **Deployed v2 · verified**, **Safe rollback · v1 restored**, **Unsafe outcome** or **Unresolved** (`frontend/src/lib/api.ts` `outcome()`). The evaluation table has separate Deployed v2, Safe rollback and Unsafe/unresolved columns.
2. **`unresolved_episodes` metric.** Added to the episode metrics and the aggregate (`backend/app/evaluation/evaluate.py`). The saved results in `models/evaluation.json` and `docs/results/evaluation.json` were regenerated by the identical re-run.
3. **Offline mock tool adapter** (`mock_tools` policy, `OfflineToolAdapter`). It shares `build_messages` and `parse_tool_call` with the live Nemotron client, uses the same three-operation batches and the same five-decision limit, and stores decisions with `mock: true`, zero tokens and no model. The UI labels it "offline, no LLM" in the selector, a banner and the inspector. It makes no network calls and does not touch the spending ledger.
4. **API-key resolution.** `NEBIUS_API_KEY` is the primary variable and `NEBIUS_TOKEN_FACTORY_KEY` the fallback. If both are set to different values, the backend reports a configuration error in `/api/health` and Settings without echoing either value. Tests cover this.
5. **Public-mode bug fix.** The access guard used to block every path, including the SPA shell. A protected deployment could therefore never load the page where the token is entered. The guard now protects only `/api/*`, except health. A test covers this.
6. **Docker and Render.** The Dockerfile listens on `$PORT` (default 8000). The compose `models` volume was removed because it would have shadowed rebuilt checkpoints. `render.yaml` was added (free Docker web service, generated workspace token, Nebius disabled).
7. **Tests.** Added backend tests for the key fallback and conflict, the mock adapter and the public-mode shell. Added a browser test for the mock adapter labelling. Browser assertions were updated to check the specific outcome.
8. **Display fix.** "Ppo" is now shown as "PPO".
